# PetProjects
This repo will contain all of the projects I am focusing on that are light touch and often vibe coded to deliver a quick output or process. These are not formally engineered projects.

## Projects

- [**GeoRanker for socials**](./georanker-for-socials/) — reads daily GeoRankl score submissions from a WhatsApp group, picks the winner (with tie-break playoffs), tracks a cumulative points tally, and produces the results message to post back to the group. Runs in a zero-risk **export mode** (parses a WhatsApp "Export chat") by default, with an optional fully-automated live bot mode.
- **[Auto Journal](AutoJournal/)** — a native iOS app that auto-writes a short daily diary entry grounded in your camera roll, activity/biometrics (Apple Health/WHOOP) and the places you went, using GitHub Models for the narrative.
- **[Auto Journal — Web](AutoJournalWeb/)** — a cross-platform (Windows/macOS/Linux) web app that auto-writes a short daily diary entry grounded in your photos, activity/biometrics (WHOOP), reverse-geocoded places, and — unlike the iOS app — your **WhatsApp, Messenger and call history** via exports. Node/Express + GPT‑5.5 through GitHub Models.
